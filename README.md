# Thank you Board

Peer recognition board, September 2026 to March 2027. One static file, no build step.

- `index.html` is the whole app. Setup notes (Firestore, roster, months, shelf) are in the comment at the top of that file.
- Hosted with GitHub Pages from the `main` branch.

To change anything: edit `index.html`, commit, push. Pages redeploys in about a minute.
